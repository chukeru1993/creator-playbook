# 同步与发布说明

## 日常同步

在仓库根目录完成内容与文档检查后执行：

```bash
git status --short
git diff --check
git add <本次要发布的路径>
git commit -m "<type>: <change>"
git push
```

首次发布或换远程时，先用 `git remote -v` 确认目标仓库，再按实际分支策略设置 `origin`。不要把初始化命令、远程地址或某台机器上的绝对路径写进方法资产。

## 每次推送前检查

- [ ] 新内容是可复用 Skill、样式规范或分镜方法，而不是某个项目的交付物。
- [ ] 新增或更新的文件已经登记到 资产索引。
- [ ] 根 README、目录 README 与相关工作流文档的链接、范围和当前目录结构一致。
- [ ] 根目录的 MIT LICENSE 文件存在，且新增内容可以按 MIT 许可发布。
- [ ] Skill 目录包含它运行所需的全部文件和元数据。
- [ ] 音效 Skill 只引用外部的、可访问的 `sfx-catalog.yaml`；没有提交项目 cue、试听结果、未授权音频、私有来源或本机绝对路径。
- [ ] Markdown 链接、相对路径和模板占位符均已检查。
- [ ] 没有提交录屏、音频、导出文件、密钥、私密信息或无授权素材。

## 推荐提交粒度

一次提交只解决一个明确的资产变化，例如：

    skill: refine hook audit
    skill: add semantic SFX spotting
    styles: add vertical video variant
    storyboard: improve scene-card checklist

不要将 Skill 迭代、样式大改和无关格式化混在一次提交中。
